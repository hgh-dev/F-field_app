F-Field 개인정보처리방침

시행일: 2026년 9월 11일

F-Field는 현장 지도 확인, 위치 기록, 도형 기록, 사진 첨부, 파일 저장 및 불러오기 기능을 제공하는 앱입니다. 본 방침은 F-Field가 어떤 정보를 처리하고, 어디에 저장하며, 사용자가 데이터를 어떻게 삭제할 수 있는지 설명합니다.

1. 개발자 정보

  • 앱 이름: F-Field
  • 개발자: hgh-dev
  • 문의 이메일: hussell.app@gmail.com

2. 처리하는 정보

  • 계정 정보: Google 로그인과 Supabase Auth를 통해 이메일 주소, 사용자 ID, 프로필 이름, 프로필 이미지 주소, 로그인 세션 정보가 처리될 수 있습니다.
  • 권한 및 인증 정보: 권한 확인을 위해 사용자 ID, 권한 등급, 권한 부여 출처, 인증코드 해시, 사용 여부, 만료일, 사용 시각이 Supabase에서 처리될 수 있습니다. 인증코드 원문은 저장하지 않습니다.
  • 위치정보: 현재 위치 표시, 현재 위치 이동, GPS 트랙 기록, 점/선/면 기록 중 현재 위치 좌표 추가, 내 위치 공유 텍스트 생성에 사용됩니다.
  • 트랙 복구 정보: 완료되지 않은 GPS 트랙의 좌표, 정확도, 기록시각과 화면 이탈 구간 등이 기기에 임시 저장될 수 있습니다.
  • 기록 데이터: 프로젝트 이름, 점/선/면 기록, 기록명, 메모, 스타일 정보, 검색 기록, 앱 설정값이 기기 내부에 저장될 수 있습니다.
  • 사진 및 파일: 사용자가 직접 선택하거나 촬영한 사진, GeoJSON, GPX, Shapefile, PMTiles, MBTiles 등 사용자가 직접 선택한 파일의 내용이 앱 기능에 사용될 수 있습니다.
  • 사용자지도 및 오프라인 지도: 사용자가 등록한 지도 이름·주소·스타일·표시 설정, 불러온 지도 파일, 사용자가 선택한 범위의 오프라인 지도 타일과 패키지 정보가 기기 내부에 저장될 수 있습니다.
  • 사진 메타데이터: 사진 기록 기능에서 사용자가 직접 선택한 사진에 촬영일시와 GPS 위치정보가 포함된 경우, 해당 정보를 기기에서 읽어 기본 기록명을 생성하고 사진 촬영 위치에 지도 기록을 배치할 수 있습니다.

3. 정보 사용 목적

  • 지도 위 현재 위치와 현장 기록 표시
  • GPS 트랙 및 현장 기록 생성
  • Google 로그인, 권한 확인, 인증코드 검증
  • 기록 데이터 백업 및 복원
  • 사진이 첨부된 현장 기록 관리
  • 사진의 촬영일시를 이용한 기본 기록명 생성 및 사진 GPS 위치를 이용한 지도 기록 배치
  • GeoJSON, GPX, Shapefile 등 외부 파일 불러오기 및 내보내기
  • 사용자지도 등록 및 사용자가 선택한 범위의 오프라인 지도 저장
  • 주소 검색, 지적 조회, 지도 표시
  • 앱 설정 저장 및 사용자 편의 기능 제공

4. 앱 권한 및 사진 메타데이터

  • 위치 권한: 현재 위치 표시, 현위치 기록 및 GPS 트랙 기능을 사용할 때 요청할 수 있습니다.
  • 위치 포그라운드 서비스 권한(FOREGROUND_SERVICE, FOREGROUND_SERVICE_LOCATION): Android에서 사용자가 시작한 GPS 트랙을 화면이 꺼지거나 다른 앱을 사용하는 동안에도 계속 기록하기 위해 사용합니다.
  • 알림 권한(POST_NOTIFICATIONS): Android에서 GPS 트랙 진행 중임을 지속 알림으로 표시하고 알림에서 기록을 중지할 수 있도록 제공하기 위해 요청할 수 있습니다.
  • 사진 위치정보 접근 권한(ACCESS_MEDIA_LOCATION): Android 10 이상에서 사용자가 직접 선택한 사진의 원본 EXIF GPS 위치정보를 읽기 위해 요청할 수 있습니다.

사진 위치정보 접근 권한을 거부해도 사진 선택과 일반적인 사진 첨부는 가능하지만, 사진의 GPS 위치를 이용한 자동 기록 배치 기능은 제한될 수 있습니다. F-Field는 기기의 전체 사진 보관함을 임의로 조회하지 않으며, Android 시스템 선택기에서 사용자가 직접 선택한 사진만 처리합니다.

사진의 EXIF 촬영일시와 GPS 위치정보는 해당 기능을 수행하기 위해 기기에서 처리되며 자체 기록 서버로 전송되지 않습니다. 원본 EXIF 메타데이터 자체는 별도 데이터 항목으로 저장하지 않지만, 처리 결과로 생성된 기록명과 좌표는 해당 현장 기록의 일부로 기기에 저장될 수 있습니다.

Android 앱에서 사용자가 트랙 기록을 직접 시작하면 위치 포그라운드 서비스가 실행됩니다. 화면을 끄거나 다른 앱을 사용해도 지속 알림이 표시되는 동안 위치정보를 처리하여 트랙을 계속 기록할 수 있습니다. 트랙 완료·취소 또는 알림의 중지 버튼을 선택하면 이 처리를 중지합니다. F-Field는 ACCESS_BACKGROUND_LOCATION(항상 허용) 권한을 요청하지 않습니다.

웹에서는 브라우저가 페이지의 위치 접근을 허용하는 동안에만 기록합니다. 화면을 끄거나 다른 앱으로 이동하면 브라우저 또는 운영체제 정책에 따라 위치 수신이 중단될 수 있습니다.

5. 외부 서비스 이용

앱 기능 제공을 위해 다음 외부 서비스를 이용합니다. 각 서비스는 요청 처리 과정에서 IP 주소, 기기·브라우저 정보, 접속 기록 등 통상적인 네트워크 정보를 자체 정책에 따라 처리할 수 있습니다.

  • Google: Google 로그인과 계정 인증. 자세한 내용은 Google 개인정보처리방침에서 확인할 수 있습니다.
  • Supabase: 로그인 세션, 사용자 ID·이메일·프로필, 권한 확인, 인증코드 검증, 회원탈퇴 처리. 자세한 내용은 Supabase 개인정보처리방침에서 확인할 수 있습니다.
  • VWorld 지도/API: 배경지도·지적도 타일, 주소 검색과 지적 조회. 검색어, 좌표 또는 조회 위치가 요청에 포함될 수 있습니다.
  • Esri 지도: 항공영상 배경지도 타일 요청. 현재 지도 범위와 확대 수준이 요청에 반영될 수 있습니다.
  • 사용자가 직접 등록하거나 여는 외부 서비스: XYZ·WMS 등 사용자지도 주소, 네이버·카카오·Google 지도 검색, 토지e음·K-GeoP 조회. 사용자가 해당 기능을 실행할 때 검색어, 좌표, 필지번호 또는 지도 요청 정보가 선택한 서비스로 전달될 수 있습니다.

F-Field는 광고 SDK와 이용행태 분석 SDK를 사용하지 않으며, 현장 기록·사진·프로젝트를 자체 기록 서버에 자동 업로드하지 않습니다. 사용자가 직접 공유하거나 외부 저장 위치를 선택한 경우에는 선택한 앱 또는 저장 서비스의 정책이 적용됩니다.

6. 정보의 공유

F-Field는 사용자가 작성한 기록, 사진, 프로젝트 데이터를 제3자에게 판매하지 않습니다. 다만 다음 경우에는 사용자의 선택 또는 앱 기능 수행에 따라 정보가 외부로 전달될 수 있습니다.

  • Google 로그인 과정에서 Google 및 Supabase로 계정 정보가 처리되는 경우
  • 권한 인증, 인증코드 검증, 회원탈퇴 처리를 위해 Supabase로 요청이 전송되는 경우
  • 지도 표시, 주소 검색, 지적 조회 또는 사용자가 등록한 온라인 사용자지도를 위해 외부 지도/API 서비스에 요청이 전송되는 경우
  • 사용자가 기록 파일, 사진, 위치 텍스트를 다른 앱으로 공유하는 경우
  • 사용자가 외부 지도 앱을 여는 경우

7. 보관 및 파기

앱 내부에 저장된 기록, 사진, 프로젝트, 검색 기록, 사용자지도, 오프라인 지도 및 설정값은 사용자가 해당 항목을 삭제하거나 앱 데이터를 초기화하기 전까지 기기에 보관됩니다. Supabase에 저장된 계정 정보와 권한 정보는 사용자가 회원탈퇴를 요청하면 삭제됩니다.

단, 기기에 저장된 현장 기록, 프로젝트, 사진, 사용자지도와 오프라인 지도는 회원탈퇴만으로 자동 삭제되지 않을 수 있으므로 앱 내 항목별 삭제 또는 초기화, Android 앱 데이터 삭제, 앱 삭제를 통해 별도로 삭제해야 합니다. 필요한 경우 삭제 전에 데이터 백업 기능으로 백업 파일을 저장해야 합니다.

진행 중인 GPS 트랙은 예기치 않은 종료나 새로고침 뒤 복구할 수 있도록 기기에 임시 저장됩니다. 정상적으로 완료하거나 취소하면 임시 데이터가 삭제되고, 중단된 경우에는 사용자가 복구 또는 삭제할 때까지 보관될 수 있습니다. Android 앱 데이터 삭제·앱 삭제 또는 웹 브라우저의 사이트 데이터 삭제로도 삭제할 수 있습니다.

선택한 사진에서 읽은 원본 EXIF 촬영일시와 GPS 메타데이터는 기능 처리 후 별도 항목으로 보관하지 않습니다. 다만 이를 이용해 생성된 기록명과 지도 좌표는 사용자가 해당 기록을 삭제할 때까지 보관될 수 있습니다.

기기 내부 데이터는 앱의 삭제 기능, 앱 데이터 초기화 또는 앱 삭제를 통해 파기됩니다. Supabase에 저장된 계정 및 권한 정보는 회원탈퇴 처리 시 삭제하며, 전자적 파일은 복구가 어렵도록 해당 서비스와 시스템이 제공하는 삭제 방식으로 처리합니다.

8. 이용자의 권리와 행사 방법

사용자는 자신의 개인정보에 대해 열람, 정정, 삭제, 처리정지 및 동의 철회를 요청할 수 있습니다. 앱의 기록·프로젝트 삭제, 앱 데이터 초기화, 회원탈퇴 기능을 이용하거나 아래 문의 이메일로 요청할 수 있습니다. 요청자는 본인 확인에 필요한 최소한의 정보를 요구받을 수 있으며, 관련 법령에서 정한 사유가 있는 경우 요청이 제한될 수 있습니다.

9. 계정 삭제

계정 삭제는 앱의 설정 또는 계정 메뉴에서 회원탈퇴를 선택해 진행할 수 있습니다. 앱에서 계정 삭제가 되지 않는 경우 hussell.app@gmail.com 으로 삭제 요청을 보낼 수 있습니다. 자세한 내용은 계정 삭제 안내를 확인하세요.

10. 기기 저장소와 자동 수집 장치

F-Field는 웹 저장소(localStorage), IndexedDB, Android WebView 저장소, Android 앱 전용 내부 저장소와 서비스 워커 캐시를 사용해 현장 기록, 사진, 검색 기록, 사용자지도, 오프라인 지도, 앱 설정, 로그인 세션 및 완료되지 않은 GPS 트랙의 복구용 임시 정보를 기기에 저장할 수 있습니다. 이는 광고 추적용 쿠키가 아니며, 브라우저 또는 Android 설정에서 앱 데이터와 사이트 데이터를 삭제하면 함께 삭제될 수 있습니다.

11. 보안

F-Field는 사용자의 기록과 사진을 기본적으로 기기 내부 저장소에 저장합니다. 앱은 자체 기록 서버로 현장 기록 데이터를 자동 전송하지 않습니다. Google, Supabase, 외부 지도/API 서비스와의 통신은 해당 서비스가 제공하는 HTTPS 주소를 사용합니다.

12. 자동화된 결정

F-Field는 사용자에게 법적 효과 또는 중대한 영향을 주는 자동화된 결정을 하지 않습니다. 서버에 저장된 권한 등급에 따라 앱 기능의 이용 가능 여부를 표시할 수 있으나, 이는 계정에 부여된 기존 권한을 적용하는 기능입니다.

13. 아동 개인정보

F-Field는 아동을 대상으로 하는 앱이 아니며, 아동의 개인정보를 의도적으로 수집하지 않습니다.
