F-Field 계정 삭제 안내

시행일: 2026년 5월 17일

F-Field에서 Google 로그인으로 생성된 계정은 앱 안에서 직접 삭제할 수 있습니다. 계정 삭제 시 Supabase Auth 계정과 권한 정보가 삭제됩니다.

앱에서 삭제하는 방법

  1. F-Field 앱을 실행합니다.
  2. 설정 또는 계정 메뉴에서 로그인 상태를 확인합니다.
  3. 회원탈퇴를 선택합니다.
  4. 회원탈퇴 안내를 확인합니다.
  5. 확인 입력란에 안내된 문구를 입력한 뒤 최종 탈퇴를 누릅니다.

삭제되는 서버 데이터

  • Google 로그인으로 생성된 F-Field 계정 정보
  • Supabase Auth 사용자 ID
  • Supabase에 저장된 권한 등급과 권한 부여 출처
  • 해당 계정의 로그인 세션

기기에 남을 수 있는 데이터

기기 내부에 저장된 현장 기록, 프로젝트, 사진, 설정값은 계정 삭제만으로 자동 삭제되지 않을 수 있습니다. 이 데이터는 앱 내 기록 삭제, 프로젝트 초기화, Android 앱 데이터 삭제 또는 앱 삭제를 통해 지울 수 있습니다.
