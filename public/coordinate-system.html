F-Field 좌표계 안내

최종 업데이트: 2026년 9월 11일

F-Field의 기본 좌표계는 WGS84 경위도(EPSG:4326)입니다.

지도 화면

앱 내부 지도 좌표는 Leaflet 기본 방식인 lat, lng를 사용하며, WGS84(EPSG:4326) 기준입니다.

배경지도 타일

VWorld, Esri 같은 배경지도는 일반 웹지도 방식인 Web Mercator(EPSG:3857 계열) 타일 체계로 표시됩니다. 사용자가 직접 기록하고 확인하는 좌표는 WGS84 위도/경도입니다.

기록관리 저장 좌표

점, 선, 면 기록은 GeoJSON 형태로 저장되며, 좌표는 [경도, 위도] 순서의 WGS84(EPSG:4326) 기준입니다.

현재 위치/GPS

브라우저 위치 API 또는 Android 위치 서비스에서 받은 WGS84 위도/경도를 그대로 사용합니다. Android 앱의 트랙 기록은 사용자가 직접 시작한 위치 포그라운드 서비스에서 처리하므로 화면을 끄거나 다른 앱을 사용해도 지속 알림이 표시되는 동안 계속될 수 있습니다. 웹은 브라우저 정책에 따라 화면이 꺼지거나 페이지가 숨겨지면 위치 수신이 중단될 수 있습니다.

완료되지 않은 트랙을 복구하기 위해 좌표를 기기에 임시 저장하더라도 좌표계는 WGS84(EPSG:4326)로 유지됩니다.

주소 조회 및 지적 조회

VWorld 주소 조회와 지적 조회 요청은 EPSG:4326 좌표를 기준으로 처리됩니다.

좌표 표시 방식

도분초와 소수점은 WGS84 위도/경도를 표시 형식만 바꿔 보여줍니다.

TM 좌표(EPSG:5186)는 WGS84 좌표를 EPSG:5186으로 변환해 화면에 표시합니다. 저장 좌표계가 EPSG:5186으로 바뀌는 것은 아닙니다.

거리 및 면적 계산

거리와 면적은 저장된 WGS84 좌표를 계산 시 EPSG:5179로 변환해 산출합니다. 결과만 m, ㎡, 평 단위로 표시됩니다.

국가지점번호 검색

국가지점번호는 EPSG:5179 기준으로 계산한 뒤, 지도 표시를 위해 WGS84(EPSG:4326)로 변환합니다.

SHP 불러오기

기록관리와 사용자지도에서 SHP ZIP을 불러오면 ZIP 안의 .prj 파일을 먼저 읽어 원본 좌표계를 확인합니다. 원본이 EPSG:4326이면 좌표를 그대로 사용하고, 다른 지원 좌표계이면 모든 점·선·면과 다중 도형의 실제 좌표값을 WGS84(EPSG:4326)로 재투영한 뒤 표시합니다. 3차원 좌표의 높이(Z) 값은 보존합니다.

자동 판별 및 변환을 지원하는 좌표계는 EPSG:4326, EPSG:5174, EPSG:5179, EPSG:5181, EPSG:5186, EPSG:5187, EPSG:5188입니다. 특히 EPSG:5174는 Bessel 1841/Korean 1985 기준의 datum 변환을 함께 적용합니다.

.prj가 없거나 해석할 수 없는 경우에는 좌표를 임의로 추정하지 않고 경고를 표시합니다. 원본 좌표계를 알고 있다면 불러오기 화면에서 직접 선택할 수 있습니다. 변환 후 대한민국 확인 범위(경도 124~132, 위도 33~39)를 크게 벗어나면 점검용 경고를 남기지만, 이 범위로 좌표계를 추정하지는 않습니다.

PMTiles / MBTiles / XYZ / WMS

타일 지도는 일반 웹지도 타일 체계를 전제로 합니다. PMTiles와 MBTiles는 Web Mercator(EPSG:3857) 기준으로 제작된 파일을 권장합니다.
