# F-Field 도움말

F-Field는 현장에서 지도 위에 점, 선, 면, 사진, 메모를 기록하고 프로젝트 단위로 관리하는 지도 기록 앱입니다. 토지 위치 확인, 지적 조회, 현장 측량, 사용자지도 불러오기, 파일 내보내기와 백업을 한 화면에서 처리할 수 있습니다.

> 앱에서 표시되는 지도와 좌표는 현장 확인과 기록 보조용입니다. 법적 경계 확정, 인허가 판단, 측량 성과물 제출용으로 사용하기 전에 반드시 공식 자료와 전문 측량 결과를 확인하세요.

## 1. 기본 화면

### 지도 이동

- 손가락으로 드래그하면 지도를 이동합니다.
- 두 손가락을 벌리거나 오므리면 확대/축소합니다.
- 오른쪽의 내 위치 버튼을 누르면 현재 GPS 위치로 이동합니다.
- 추적 버튼을 켜면 사용자가 이동할 때 지도가 현재 위치를 따라갑니다.

### 현재 위치

- 앱은 Android 위치 권한 또는 브라우저 위치 API에서 받은 WGS84 위도/경도를 사용합니다.
- 실외에서 GPS 수신 상태가 좋아야 위치 정확도가 높습니다.
- 건물 내부, 산림 밀집 지역, 계곡, 고층 건물 주변에서는 오차가 커질 수 있습니다.

## 2. 지도 관리

왼쪽 위 메뉴를 열고 `지도 관리` 탭에서 지도 레이어를 켜고 끌 수 있습니다.

### 기본지도

- VWorld 위성지도
- Esri 위성지도
- VWorld 일반지도
- 하이브리드 지도
- 행정경계
- 연속지적도
- LX맵

기본지도, 지적도, 행정경계는 타일 모양 스타일 버튼을 눌러 투명도를 조절할 수 있습니다. 이 투명도는 앱 실행 중에만 적용되며, 앱을 다시 시작하면 기본값으로 돌아갑니다.

### 주제도

주제도 섹션에서는 개발제한구역, 산림보호구역, 자연환경보전지역, 도시지역, 농림지역, 도로, 비행제한구역, 산림입지토양도 등 여러 주제도 레이어를 확인할 수 있습니다.

- 주제도 기본 투명도는 0.8입니다.
- 주제도 투명도도 앱 실행 중에만 유지되고, 앱을 다시 시작하면 기본값으로 돌아갑니다.
- 주제도를 많이 켜면 지도 표시가 느려질 수 있습니다.

### 오프라인 지도

오프라인 지도 기능은 테스트 중인 기능으로, 관리자 계정과 인증된 회원에게 표시됩니다.

- 현재 화면의 지도 데이터를 미리 저장해 통신이 불안정한 현장에서 참고할 수 있습니다.
- 저장 가능한 범위와 품질은 지도 종류, 현재 줌 레벨, 네트워크 상태에 따라 달라질 수 있습니다.
- 오프라인 지도는 보조 기능이므로 중요한 현장에서는 필요한 자료를 별도로 준비하세요.

## 3. 검색과 지적 정보 확인

### 검색

오른쪽 위 검색 버튼에서 다음 정보를 검색할 수 있습니다.

- 지번 주소
- 도로명 주소
- 장소명
- 위도/경도 좌표
- 국가지점번호

검색 결과를 선택하면 해당 위치로 지도가 이동하고, 하단 바텀시트에 주소와 좌표 정보가 표시됩니다.

### 지도 더블 탭

지도에서 원하는 위치를 빠르게 두 번 누르면 해당 지점의 주소와 지적 정보를 조회합니다. 조회된 지적 경계가 있으면 지도 위에 표시되고, 하단 바텀시트에서 관련 기능을 사용할 수 있습니다.

### 지적 바텀시트 기능

- 주소, 좌표, 우편번호 확인
- 텍스트 복사
- 점 기록 저장
- 면 기록 저장
- 위치 공유
- 외부 지도 앱 또는 내비게이션 앱으로 열기
- 토지e음 조회
- K-GeoP 조회

## 4. 기록 추가

오른쪽 아래 `+` 버튼을 눌러 기록 도구를 엽니다.

### 점 기록

특정 위치를 점으로 저장합니다.

- 기본 마커, 원, 삼각형, 사각형, 오각형, 마름모, 별 모양을 선택할 수 있습니다.
- 더보기 버튼을 누르면 자주 쓰는 이모지 마커를 선택할 수 있습니다.
- 지적 바텀시트에서 저장한 점은 기본 마커로 저장됩니다.
- 일반 점 추가와 사용자지도 SHP 점 유형은 원형 마커를 기본으로 사용합니다.

### 선 기록

거리, 경로, 경계 일부를 선으로 저장합니다.

- 선없음, 실선, 기본파선은 기본 목록에 표시됩니다.
- 더보기를 누르면 긴 파선, 점선, 일점쇄선, 이점쇄선, 임반선 등을 선택할 수 있습니다.
- 임반선은 실선 위에 일정 간격의 둥근 점을 함께 표시하는 방식입니다.

### 면 기록

구역, 필지, 조사 범위를 면으로 저장합니다.

- 기본 채우기는 `면없음`입니다.
- 면 채우기는 면없음, 단색, 가로선, 세로선, 대각선, 격자 등으로 설정할 수 있습니다.
- 무늬 채우기는 단색 배경을 채우지 않고, 선택한 색상의 선 무늬만 표시합니다.
- 투명도를 조절하면 무늬도 함께 투명해집니다.

### 트랙 기록

걸어간 경로를 GPS 기반 선으로 기록합니다. 인증된 회원과 관리자 계정에서 사용할 수 있습니다.

- 설정에서 트랙 기록 간격을 2m, 5m, 10m, 20m 중 선택할 수 있습니다.
- 간격이 짧을수록 정밀하지만 저장 용량과 배터리 사용량이 늘어납니다.
- 트랙 기록 중에는 화면을 끄거나 다른 앱으로 전환하지 않는 것이 좋습니다.
- 절전 모드를 사용하면 화면 밝기 부담을 줄일 수 있습니다.

### 사진 추가

사진과 위치를 함께 기록합니다. 인증된 회원과 관리자 계정에서 사용할 수 있습니다.

- 카메라로 촬영하거나 갤러리에서 사진을 선택할 수 있습니다.
- 사진은 앱 내부 기록에 첨부됩니다.
- 기록 바텀시트에서 사진을 확인하고 저장할 수 있습니다.

## 5. 기록 수정과 스타일 설정

지도 위 기록을 누르거나 기록관리 목록에서 기록을 선택하면 하단 바텀시트가 열립니다.

### 기록 바텀시트

- 점 기록: 좌표 확인
- 선 기록: 거리 확인
- 면 기록: 면적 확인
- 메모 작성
- 사진 확인 및 추가
- 기록 수정
- 삭제
- 레이어 순서 변경
- 프로젝트 이동

### 도형 수정

기록의 더보기 메뉴에서 수정을 선택하면 점, 선, 면의 위치를 수정할 수 있습니다.

- 기존 꼭지점을 드래그해 이동합니다.
- 선분 사이의 `+` 버튼을 눌러 새 꼭지점을 추가합니다.
- 면 기록은 구멍 그리기와 구멍 채우기를 사용할 수 있습니다.

### 스타일 설정

기록관리 목록의 스타일 버튼을 누르면 지도에 표시되는 스타일을 바꿀 수 있습니다.

- 점: 마커 모양, 색상, 크기
- 선: 색상, 선 굵기, 선 종류
- 면: 면 색상, 면 채우기, 면 투명도, 테두리 색상, 테두리 굵기, 테두리 선 종류

스타일 설정 버튼 안의 미리보기는 실제 지도에 그려지는 스타일과 최대한 비슷하게 표시됩니다.

## 6. 기록 관리

왼쪽 메뉴의 `기록 관리` 탭에서 현재 프로젝트의 기록을 관리합니다.

### 기록 목록

- 체크박스를 끄면 해당 기록을 지도에서 숨깁니다.
- 기록 이름을 누르면 해당 위치로 지도가 이동합니다.
- 스타일 버튼을 누르면 스타일 설정 바텀시트가 열립니다.
- 더보기 메뉴에서 수정, 삭제, 프로젝트 이동, 레이어 순서 변경 등을 사용할 수 있습니다.

### 정렬과 그룹

- 기록을 이름, 생성일 등 기준으로 정렬할 수 있습니다.
- 여러 기록을 선택해 그룹으로 묶을 수 있습니다.
- 그룹 단위로 표시/숨김을 제어할 수 있습니다.

### 불러오기

기록관리의 불러오기 버튼으로 다음 파일을 가져올 수 있습니다.

- GeoJSON
- SHP ZIP
- GPX

SHP 파일은 ZIP 안에 `.shp`, `.shx`, `.dbf`가 포함되어 있어야 합니다. 좌표계 정보인 `.prj`가 있으면 자동 선택을 사용할 수 있고, `.prj`가 없거나 잘못된 경우 불러오기 화면에서 좌표계를 직접 선택할 수 있습니다.

### 내보내기

- 개별 기록은 GeoJSON, SHP, GPX로 내보낼 수 있습니다.
- 현재 프로젝트는 GeoJSON 파일로 저장할 수 있습니다.
- 사진이 포함된 기록은 백업 용량이 커질 수 있습니다.

## 7. 프로젝트 관리

프로젝트는 기록을 묶어 관리하는 폴더와 비슷한 단위입니다.

### 프로젝트 전환

기록관리 상단에서 프로젝트를 선택하면 해당 프로젝트의 기록만 지도에 표시됩니다.

### 프로젝트 생성과 이름 변경

프로젝트 관리 탭에서 새 프로젝트를 만들 수 있습니다. 프로젝트명은 현장명, 조사일, 업무명 등으로 구분해 두면 관리하기 쉽습니다.

### 프로젝트 저장

현재 프로젝트의 기록을 하나의 GeoJSON 파일로 저장합니다. 앱 삭제, 기기 변경, 데이터 초기화 전에는 반드시 필요한 프로젝트를 저장하세요.

### 전체 백업

프로젝트 관리의 데이터 백업 기능은 여러 프로젝트를 ZIP 파일로 묶어 저장합니다.

- 프로젝트별 GeoJSON
- 기록명
- 메모
- 스타일
- 첨부 사진

앱 내부 기록은 기본적으로 기기에 저장되므로, 앱 삭제나 앱 데이터 초기화 전에 반드시 백업하세요.

## 8. 사용자지도

사용자지도는 사용자가 가진 지도 파일이나 지도 URL을 앱에 추가해 배경 또는 참고 레이어로 표시하는 기능입니다.

### 지원 형식

- SHP ZIP
- XYZ 타일 URL
- WMS
- PMTiles
- MBTiles

### SHP 불러오기

SHP 파일은 ZIP 파일로 불러옵니다.

- ZIP 안에 `.shp`, `.shx`, `.dbf`가 필요합니다.
- `.prj`가 있으면 자동 좌표계 선택을 사용할 수 있습니다.
- 좌표계가 맞지 않으면 위치가 틀어질 수 있으므로 직접 좌표계를 선택하세요.
- 점 유형 SHP는 원형 마커로 표시됩니다.

### 타일지도 불러오기

XYZ, WMS, PMTiles, MBTiles는 일반 웹지도 타일 체계를 전제로 합니다.

- 보통 EPSG:3857 Web Mercator 타일이어야 정상 위치에 표시됩니다.
- PMTiles와 MBTiles 파일이 잘못 만들어졌거나 서버에서 파일 접근을 막으면 불러오지 못할 수 있습니다.
- NAS, GitHub Pages, 웹 서버에서 불러올 때는 파일 URL, CORS, 404 오류를 확인하세요.

### 사용자지도 스타일

- SHP 사용자지도는 스타일 설정 버튼으로 점, 선, 면 스타일을 바꿀 수 있습니다.
- XYZ, WMS, PMTiles, MBTiles 사용자지도는 타일 아이콘을 눌러 투명도를 조절할 수 있습니다.
- 사용자지도 타일 투명도는 사용자지도 설정에 저장됩니다.

## 9. 설정

설정은 왼쪽 메뉴 하단의 설정 버튼에서 열 수 있습니다.

### 계정

- Google 로그인으로 계정을 사용할 수 있습니다.
- 인증코드가 있는 경우 인증코드를 입력해 인증된 회원 권한을 활성화할 수 있습니다.
- 인증된 회원은 인증정보 메뉴에서 인증일, 만료일, 남은 기간을 확인할 수 있습니다.
- 관리자 계정은 관리자 메뉴에서 회원 권한, 인증코드, 공지 뱃지를 관리할 수 있습니다.

### 좌표계 안내

좌표계 안내 메뉴에서 앱의 좌표 저장, 표시, 계산 기준을 확인할 수 있습니다.

핵심 기준은 다음과 같습니다.

- 기본 저장 좌표계: WGS84 경위도(EPSG:4326)
- 지도 화면: Leaflet 기반 위도/경도
- 배경지도 타일: Web Mercator 타일 체계
- 기록 저장: GeoJSON `[lng, lat]`
- TM 좌표 표시: EPSG:5186으로 변환해 화면 표시
- 거리/면적 계산: EPSG:5179로 변환 후 m, m², ha 계산
- 국가지점번호 계산: EPSG:5179 사용

### 좌표 표시 방식

화면에 표시되는 좌표 형식을 선택합니다.

- 도분초
- 소수점
- TM 좌표(EPSG:5186)

이 설정은 표시 방식만 바꾸며, 저장 좌표계가 바뀌지는 않습니다.

### 스냅 기능

측량 또는 수정 중 주변 꼭지점과 선에 맞춰 그릴 수 있게 도와줍니다.

### 트랙 기록 간격

GPS 트랙 기록 시 위치를 저장할 최소 이동 거리를 설정합니다.

### 축소 시 도형 단순화

지도를 멀리 축소했을 때 선과 면을 단순화해 렌더링 부담을 줄입니다. 기본값은 꺼짐입니다.

### 공지사항

공지사항 버튼은 F-Field 공지 블로그로 연결됩니다.

공지사항:
https://f-field.blogspot.com/

관리자가 설정한 기간 동안 공지사항 버튼에 파란 뱃지가 표시될 수 있습니다.

## 10. 권한과 기능 제한

F-Field는 계정 권한에 따라 일부 기능이 다르게 표시됩니다.

### 비회원 또는 무료 회원

- 기본 지도 보기
- 검색
- 점, 선, 면 기록
- 기록관리
- 프로젝트 관리
- 사용자지도 일부 기능

### 인증된 회원

## 11. 데이터 저장과 백업

F-Field의 현장 기록과 사진은 기본적으로 사용자의 기기 내부에 저장됩니다.

### 반드시 백업해야 하는 경우

- 앱을 삭제하기 전
- 앱 데이터를 초기화하기 전
- 휴대폰을 변경하기 전
- 브라우저 캐시나 사이트 데이터를 삭제하기 전
- 중요한 현장 조사가 끝난 후

### 권장 백업 방법

- 현재 프로젝트만 저장: `기록 관리 > 프로젝트 저장`
- 전체 프로젝트 백업: `프로젝트 관리 > 데이터 백업`

계정 삭제는 Supabase 계정과 권한 정보를 삭제하는 절차입니다. 기기 내부에 저장된 기록, 사진, 프로젝트는 계정 삭제만으로 자동 삭제되지 않을 수 있으므로 별도로 삭제하거나 앱 데이터를 초기화해야 합니다.

## 12. 현장 사용 팁

### GPS 정확도 높이기

- 하늘이 잘 보이는 곳에서 사용하세요.
- 위치가 흔들리면 잠시 기다린 뒤 기록하세요.
- 정밀한 측량이 필요한 경우 외장 GNSS 장비 사용을 권장합니다.

### Trimble Mobile Manager 사용

안드로이드에서 Trimble 장비를 사용할 경우:

1. Google Play에서 Trimble Mobile Manager를 설치합니다.
2. Android 개발자 옵션을 활성화합니다.
3. `가상 위치 앱 선택`에서 Trimble Mobile Manager를 선택합니다.
4. GNSS 장비를 연결하고 정확도가 안정된 뒤 기록합니다.

iOS에서는 TMM 위치 권한을 적절히 설정한 뒤 장비를 연결해 사용합니다.

### 성능 관리

다음 상황에서는 앱이 느려질 수 있습니다.

- 주제도를 많이 켠 경우
- 사용자지도를 여러 개 켠 경우
- 큰 SHP, PMTiles, MBTiles 파일을 불러온 경우
- 기록이 매우 많은 프로젝트를 표시한 경우
- 복잡한 면 무늬를 많이 사용한 경우

느려질 때는 불필요한 레이어를 끄고, 기록을 프로젝트별로 나누어 관리하세요.

## 13. 문제 해결

### 지도가 보이지 않을 때

- 인터넷 연결을 확인하세요.
- VWorld 또는 외부 지도 서버 응답이 불안정할 수 있습니다.
- 너무 많은 레이어를 켰다면 일부를 꺼보세요.

### 내 위치가 맞지 않을 때

- 위치 권한이 허용되어 있는지 확인하세요.
- 실외에서 다시 시도하세요.
- 휴대폰 GPS가 안정될 때까지 기다리세요.

### 사용자지도 파일이 열리지 않을 때

- SHP ZIP에 필요한 파일이 모두 있는지 확인하세요.
- 좌표계가 맞는지 확인하세요.
- PMTiles/MBTiles가 웹지도 타일 체계로 만들어졌는지 확인하세요.
- URL이 404가 아닌지, 서버가 CORS를 허용하는지 확인하세요.

### 기록이 사라진 것처럼 보일 때

- 현재 선택된 프로젝트가 맞는지 확인하세요.
- 기록관리에서 체크박스가 꺼져 있지 않은지 확인하세요.
- 앱 데이터나 브라우저 캐시를 삭제한 경우 내부 저장 기록이 사라질 수 있습니다.
- 백업 파일이 있다면 프로젝트를 다시 불러오세요.

### Play Store 내부테스트 버전이 바로 안 보일 때

- Play Console 반영에는 시간이 걸릴 수 있습니다.
- 테스트 계정이 내부테스터 목록에 있는지 확인하세요.
- Play Store 앱 캐시를 지우거나 잠시 뒤 다시 확인하세요.
